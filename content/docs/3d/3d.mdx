# Overview 

3D models on CAD are digital designs that can be opened, viewed, edited, and prepared for printing in most modern CAD software.For this guide, the important part is that Shipwrights should be able to approve CAD models and check the properly to make sure all required files are included in github and CAD communites 

# Requirements 

* Make sure you git repo has all the editor files for eg : .f3d,.blend ,.shapr
* You should have a 3D printer to print your models 
* Your Model print files can be any of these ( .obj .step .stl .3mf )
* Make sure that you have logged hours on hackatime supported editor or with [Lapse](https://lapse.hackclub.com/) on any of your fav editors

You need to publish editor files ,along with printing files on both gihub and online printing platfroms like ( printables , makerworld etc ) 
and the picture of the printed model should be uploaded in both github and any platform you choose !!

## How to Get Editor Files ? 
You can follow these steps to export editors files from most of the common editors like fusion , onshape , blender , shaper3D . Most of the editors have similar exporting methods if you find any sort of difficulty to get the files dm [@Amu](https://hackclub.enterprise.slack.com/team/U091M21518T) for Help :)

### Onshape

<Steps>
  <Step>
 # Open Your Project
  Open your Model in Onshape
  </Step>

  <Step>

    <img src="3d-assests/onshape1.png" alt="create-build" loading="eager" />
   </Step>

### Blender

<Steps>
  <Step>
 # Open Your Project
  Open your Model in Blender
  </Step>

  <Step>
 # Getting A .Blend File 
   save your project by going to File → Save (or Ctrl+S) and choose a location on your computer. Blender automatically adds the .blend extension to your project

    <Step>
 # Getting a Printable File
  From Top Right: Click File → Export → select stl 
   <img src="/3d-assests/stl.png" alt="create-pass" loading="eager" />
    <Callout type="info" title="Stl file i reccomended for blender">
stl file is one of the best file type for print and in blender exporting stl is really easy ,ensuring your mesh is manifold (watertight), has correct normals, and is triangulated
</Callout>

   </Step>
</Steps>

# Readme Requirements For 3D models

* Make sure to have onshape link if you are using onshape as a editor
* Mention the usage of any open source asset in your project and give proper credits :)
* Try to have a brief description of model
* Remeber the the **rule of three W , Why , What ,Where** so that you mention why you made this , what  is this actually ?, From where you learnt things or where are you going to use this :)
