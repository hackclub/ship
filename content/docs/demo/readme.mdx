# README Guidelines

Your project must include a `README.md` that explains what the project does and how to use it. Reviewers and users should be able to understand and test your project without guessing.

## Requirements

* **Your README must explain the project.** Include a short description of what it does and any important features. A README that only says something like "this is a calculator app" is not enough.
* **Include setup or usage instructions.** Reviewers and users should know how to run, install, or use your project.
* **Your README link must be raw.** Your README link must start with `raw.githubusercontent.com`. Other links will be rejected.
* **Do not leave template placeholders.** Replace things like `YOUR PROJECT NAME` or `[Add description here]`.
* **AI usage must be disclosed.** If you used AI tools while building your project or writing your README, explain how they were used.

---

## Minimum README Example

```md
# Calculator App

A simple calculator built with JavaScript that supports basic arithmetic operations.

## Features
- Add, subtract, multiply, divide
- Keyboard support
- Responsive layout

## How to Run
Open `index.html` in your browser.
```
---

## Common Rejection Reasons

Your submission may be rejected if:

* The README is missing or empty
* The README link is not raw
* The README contains placeholder text or template comments
* The README is too vague to understand the project
