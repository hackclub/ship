## Requirements
1. Demo must either be a link to a [Modrinth](https://modrinth.com/) or [Curseforge](https://www.curseforge.com/) page, or to a GitHub release containing the mod's `.jar` file.
2. Supported versions must be specified on the mod page and README
    - Ex: `1.20.1, 1.21.*, 26.1, etc.`
3. Supported loaders must be specified on the mod page and README
    - Ex: `Fabric, Paper, etc.`
4. Dependencies must be listed on the mod page and README
    - Ex: `Continuity, Respackopts (optional), etc.`

### Configuration
If your mod/plugin has a configuration file, it needs to meet these requirements:
1. Config path specified on the mod page and README
    - Ex: `config/MyMod.json`
2. It's recommended to have each field be documented in the README, or in the config file directly
    - Alternatively, use a mod like [Cloth Config API](https://modrinth.com/mod/cloth-config) to add support for editing the config in-game!
<Accordions type="single">

Example config taken from [FallingTree](https://modrinth.com/mod/fallingtree).
```jsonc
{
  // Should the player be sneaking for the mod to activate?
  // Options: SNEAK_DISABLE, SNEAK_ENABLE, IGNORE
  "sneakMode": "IGNORE",
  // Should the mod work in creative?
  "breakInCreative": true,
  // Should blocks drop when the mod is used in creative?
  "lootInCreative": false,
  // How notifications are shown
  // Options: CHAT, ACTION_BAR, NONE
  "notificationMode": "ACTION_BAR",
  // Tool configurations
  "tools": {
    // Items that always activate the mod
    "whitelisted": ["minecraft:oak_boat", "#minecraft:flowers"],
    // Items that never activate the mod
    "blacklisted": ["minecraft:oak_boat", "#minecraft:flowers"],
    // Allow the mod to be used with an empty hand
    "ignoreTools": false,
    // Damage taken off the tool for each block broken (set to 0 to disable)
    "damageMultiplicand": 1,
    // How much longer it will take to activate the mod (set to 0.0 to disable)
    "speedMultiplicand": 0.0,
    // Require tools to be on the whitelist
    "forceToolUsage": true
  },
  // Player configurations
  "player": {
    // Tags needed in order to use the mod
    "allowedTags": ["playerTag1", "playerTag2"]
  },
  // Enchantment configurations
  "enchantment": {
    // Require the "Chopper" enchantement in order to activate the mod
    "requireEnchant": true
  }
}
```

<Step>

### Make a new project

1. Make sure you're signed into [Modrinth](https://modrinth.com/)
2. Navigate to the [project management dashboard](https://modrinth.com/dashboard/projects)
3. Start the project creation by clicking "*Create a Project*"

![Create a new project on the Modrinth project page](/minecraft-assets/minecraft-project-new.png)

</Step>

<Step>

### Configure the project

- **Name**: How your project will be referred to.
- **Visibility**: Who can access the project. This has to be set to **Public** for all Hack Club projects.
- **Summary**: Short tagline describing the project.

![Configure the project with the required fields](/minecraft-assets/minecraft-project-configuration.png)

</Step>

<Step>

### Create a version

Once you have created the project, you can create its first version.
1. Find your project settings by going to the project management dashboard and clicking the gear icon
2. Scroll down, and open the "*Versions*" panel
3. Create a new version by clicking the "*Create version*" button

![Navigate to the project settings by clicking the gear icon](/minecraft-assets/minecraft-project-settings.png)
![Create a new version of the project](/minecraft-assets/minecraft-version-create.png)

</Step>

<Step>

### Configure the version

After you've selected your project, you can configure various properties about it. The types of properties depend on the kind of project.

- **Dependencies**: Any other mods your mod needs to run.
- **Metadata**: Required mod loaders and game versions.
- **Details**: Information regarding the version, including the version number and a changelog.
