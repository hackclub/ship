## Requirements
- Demo must be a link to a mod page on a popular mod registry, such as [Thunderstore](https://thunderstore.io/communities/) or [Nexus Mods](https://www.nexusmods.com/games/).
- The mod page should contain the dependencies for the mod.
  - Ex: `BepInExPack, R2API, Risk Of Options`
- If it isn't clear what version the mod is made for, it should be specified.
  - Ex: `Made for v1.4.1.886`
- If the game is paid (costs money to play), a video demo should be added in the README or the mod page.
