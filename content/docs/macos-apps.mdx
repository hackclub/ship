# Pack as .dmg file
## Using create-dmg
Want to pack your app into a good looking drag and drop .dmg file?
<picture>
    <source media="(prefers-color-scheme: dark)" srcSet="/macos-assets/dmg-dark.png" />
    <source media="(prefers-color-scheme: light)" srcSet="/macos-assets/dmg-light.png" />
    <img alt="screenshot of the flavortime DMG file" src="/macos-assets/dmg-light.png" />
</picture>


The easiest way to create a professional `.dmg` installer is using the [`create-dmg`](https://github.com/sindresorhus/create-dmg) tool by Sindre Sorhus.

<GithubInfo
    owner="sindresorhus"
    repo="create-dmg"
/>

<Steps>
    <Step>
    ### Installation
    
<CodeBlockTabs defaultValue="npm" groupId="package-manager">
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="npm">
      npm
    </CodeBlockTabsTrigger>

    <CodeBlockTabsTrigger value="brew">
      brew
    </CodeBlockTabsTrigger>
  </CodeBlockTabsList>

  <CodeBlockTab value="npm">
    ```bash
    npm install --global create-dmg
    ```
  </CodeBlockTab>

  <CodeBlockTab value="brew">
    ```bash
    brew install create-dmg
    ```
  </CodeBlockTab>
</CodeBlockTabs>

</Step>
<Step>
    ### Usage
    ```bash
    # create-dmg <app> [destination]
    create-dmg MyApp.app MyApp.dmg
    ```
    <img src="/macos-assets/create-dmg-demo.gif" alt="create-dmg-demo" loading="eager" />
    <Callout type="info" title="Credits">
    The above image is from the [create-dmg](https://github.com/sindresorhus/create-dmg) repository, used under the MIT License. Copyright (c) Sindre Sorhus.
    </Callout>
</Step>
    <Step>
    Wanna add some flavor to the .DMG?    
    #### With custom icon and background
    ```bash
    create-dmg MyApp.app MyApp.dmg \
        --icon MyApp.app 80 180 \
        --icon Applications 240 180 \
        --background background.png \
        --window-size 512 384
    ```
</Step>
</Steps>


Check the [documentation](https://github.com/sindresorhus/create-dmg) for more customization options like window position, text, and signing.
