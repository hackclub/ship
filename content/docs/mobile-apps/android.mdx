# Overview 

Android apps are the application which i can be installed in most of the modern andriod smartphones through any source ,For this guide, the most important part is that Shipwrights can easily download, install, and test your app using the provided APK file without complicated setup steps.For this guide, the most important part is that Shipwrights can easily download, install, and test your app using the provided APK file without complicated setup steps.

# Requirements 

* Provide an apk downloadable release on Github releases
* The app must launch on Android Smartphone with out any prior setup 
* If your app doesnt works without disabling **Play Protect** specify that in your README!
* If the app uses authentication, users must be able to create accounts and log in


# Publishing Options 

You need to publish it on a GitHub Release for `.apk`

# Readme Requirements For Adriod Apps

* Make sure to mention all the features of your app so that we dont miss any of your hardwork during testing !
* Mention the usage of any open source asset in your project and give proper credits :)
* Try to have a brief description of the app with proper usage instructions
* Remeber the the **rule of three W , Why , What ,Where** so that you mention why you made this , what  is this actually ?, From where you learnt things or where are you going to use this :)
