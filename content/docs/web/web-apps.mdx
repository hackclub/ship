## Requirements

- Demo must be a link to your published site / web app
- Any login / auth features must allow users to create accounts and log in

<Callout type="warn" title="Hosting restrictions">
  Your site **cannot** be hosted on Render, Railway, or be a tunnel link. It should be deployed somewhere permanent. These services spin down on the free tier, meaning voters may hit a cold-start delay or a dead link.
</Callout>

### Not sure which to pick?

| | Vercel | GitHub Pages |
|---|---|---|
| **Best for** | Full-stack apps (Next.js, React, etc.) | Static sites (HTML/CSS/JS) |
| **Backend support** | Yes (serverless functions) | No |
| **Database** | Yes (via integrations) | No |
| **Auto-deploy on push** | Yes (built-in) | Yes (with Actions) |
| **Custom domain** | Yes | Yes |
| **Price** | Free tier available | Free |
