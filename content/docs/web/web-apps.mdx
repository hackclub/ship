# Requirements
- Demo must be a link to your published site / web app
- Site **cannot** be hosted on onrender, railway, or be a tunnel link - it should be depoloyed somewhere permanant
- Any Login / Auth features must allow users to create accounts and log in
  - You can give a 'demo user' login to voters, but we still need to be able to create accounts

## Deploying / Publishing

Not sure how to get your site / web app online? 

You can use:
- GitHub Pages for static sites
- [Vercel](https://vercel.com) (Great for full-stack web-apps!)
- Netlify
- Something else if you prefer!

### GitHub Pages
1. Open up your repo on GitHub
2. Go to repo settings
3. In the sidebar, under `Code and Automation`, select Pages
4. Select your main branch under `branch` to deploy from a branch
5. GitHub will deploy your site (assuming there is an `index.html` in the root of the repo) and your url should be `username.github.io/reponame` - that's your demo url!

### Vercel
1. Create or login to your Vercel account and link your GitHub account
2. Create a new vercel project and select your GitHub repo
3. Vercel should auto detect the build framework (if you need one), confirm it's correct and press next
4. Vercel will make a deployment and give you a `*.vercel.app` url - this is your demo link!
